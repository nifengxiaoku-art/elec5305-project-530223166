# elec5305-project-530223166
ELEC5305 Project - Animal Sound Classification Using CNN and Data Augmentation
## Project Overview

This project investigates the use of a Convolutional Neural Network (CNN)
for animal sound classification.

Animal sound recordings from the ESC-50 dataset will be used.
The audio will be converted into Mel-spectrograms and classified using a CNN.

## Research Question

Can data augmentation improve CNN-based animal sound classification?

## Proposed Method

Animal Audio → Mel-spectrogram → CNN → Animal Class

A baseline CNN will first be trained using the original data.
Data augmentation will then be introduced and the performance will be compared.
